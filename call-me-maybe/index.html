How Teacher mode works

  • Put the iPad on the piano and allow the microphone.
  • It plays a line, then waits for you to play it note by note.
  • Blue = play this note. Green = right. Red = try again.

Practice plan

  • Part A first, with "Play each line first" on.
  • Then Part B, then the whole chorus (Part A comes back at the end).
  • In Listen mode the real song speed is about 120.

For grown-ups

Teacher mode checks which note is played, not the timing. Use it in a quiet room. If notes aren't heard, check the green mic bar moves when a key is played. Melody transcribed from the sung vocal at 0:28–0:52 of the official video; the singer's slides into notes are left out. Printable PDF.
